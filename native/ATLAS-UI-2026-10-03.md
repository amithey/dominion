# Geopolitical atlas interface

The player selected concept 2 from the four visual mockups on 2026-10-03.
The native interface now uses deep navy panels, pale gray body text, sand
selection and fine borders. Georgia/Cambria headings contrast with Segoe UI
body text. Active navigation and tabs use dark ink on sand, including icons.
Ministries share one accent rather than competing coloured navigation.
Warnings, diplomatic status and chart series retain semantic colours.

The shared theme covers the resource strip, Cabinet, ministries, research,
production, campaign setup, settings, tooltips and pause menu. The opening
screen has a subtle coordinate grid and compass ornament that does not capture
input. Existing game terrain and gameplay are preserved; the concept image's
geographic terrain is not a replacement for the game's maps.

Validation: menus-check 52/52; interface-review PASS. Actual rendered screenshots
of 13 game views were captured and the market and pause screens reviewed.
Screenshots are local in build/atlas-*.png. Godot reports its existing Windows
certificate store and test-exit cleanup diagnostics.
