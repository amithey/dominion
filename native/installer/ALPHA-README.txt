DOMINION - ALPHA 1.0.3

Thank you for testing DOMINION, a real-time strategy game of nations: cities, supply lines, research,
diplomacy, espionage, the United Nations and war.

WHAT AN ALPHA MEANS
The game can be played from the first village to a victory or a defeat, but few people have played it. Some
weapons are not balanced, some texts are rough, and an error can still happen. Your reports make it better.

HOW TO PLAY
- The game starts with a short guide (First steps). F1 shows the controls at any time.
- Pick a nation and a map on the New Game screen. Start on Easy to learn the systems.
- Esc opens the pause menu. F5 saves quickly, F9 loads the quick save.
- Testing tools: Esc > Settings > Game > Testing tools adds a Cheats button (and F8, F10) for trying things quickly.
  Please leave them off when you report balance or difficulty, and say if you used them.

WHERE THINGS ARE
- Saved games and settings:  %APPDATA%\DOMINION
- Logs:                      %APPDATA%\DOMINION\logs   (godot.log is the game's own log)
- A save that cannot be read is kept there as <name>.bad.json; nothing is deleted.

REPORTING A PROBLEM
In the game: Esc > About / Report a problem (or F1 > Report a problem). It copies a report to the clipboard
and opens the logs folder. Paste the report in your message, attach godot.log, and say what you were doing.
Please tell us the nation, the map, the difficulty and roughly how long you had played.

KNOWN ISSUES
- Very large battles (over 100 units) can run below 25 frames a second on integrated graphics.
- Tanks may stall for a moment in narrow gaps between buildings.
- The Windows installer is not signed, so Windows may warn you the first time.
- Some weapons are abstracted (see the About screen); balance is a first pass.

UNINSTALL
Use "Apps" in Windows Settings. Your saved games are kept in %APPDATA%\DOMINION; delete that folder to remove them.
