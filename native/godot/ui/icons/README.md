# DOMINION engraved icons

Original vector artwork created for this project. No emoji fonts or external image assets.
Jade/ivory/brass outlines share a 64-unit grid. Materials also have distinct silhouettes:
coins, wheat, faceted ore, oil drop, chip and uranium crystal.

`UI.icon` prefers these SVGs and falls back to the existing PNG for other names.
Keep labels/tooltips with icons: colour alone never conveys a resource or action.
